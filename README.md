## 🧠 Objetivo

Esta atividade tem como objetivo aplicar os conhecimentos de análise exploratória de dados (EDA), pré-processamento e avaliação de um **modelo de regressão**. Os alunos deverão seguir o roteiro proposto, com foco em análises bem estruturadas e fundamentadas.

---

## 📦 Instalação de Bibliotecas

Execute os comandos abaixo no ambiente caso necessário:

```bash
pip install numpy pandas matplotlib seaborn scikit-learn
pip install plotly polars
```

📂 Dataset

🔗 KC House Data - Kaggle
- https://www.kaggle.com/datasets/harlfoxem/housesalesprediction


    O dataset trata de uma variável resposta contínua (regressão).

    O aluno deverá realizar as análises considerando este dataset como base única do projeto.

## ✅ Tabela de Avaliação por Critério

| Critério                                                  | Descrição                                                                                                   | Peso (%) |
|-----------------------------------------------------------|-------------------------------------------------------------------------------------------------------------|----------|
| **1. Descrição do Dataset**                               | Nome do arquivo, origem, nº de registros, colunas, tipos de dados, dados faltantes                         | 10%      |
| **2. Análise Exploratória (EDA)**                         | Estatísticas descritivas, histogramas, boxplots, outliers, comportamentos relevantes                        | 20%      |
| **3. Correlação das Variáveis**                           | Visualização (ex: heatmap), análise de quais variáveis estão mais correlacionadas com a variável resposta   | 10%      |
| **4. Pré-processamento e Transformações**                 | Tratamento de nulos, normalização, codificação, exclusão/criação de colunas, justificação clara             | 15%      |
| **5. Treinamento de um único Modelo de Regressão**        | Ex.: LinearRegression, RandomForestRegressor, XGBoostRegressor                                              | 10%      |
| **6. Avaliação do Modelo**                                | Métricas obrigatórias: MAE, RMSE, R²; Interpretação clara dos resultados                                    | 20%      |
| **7. Conclusão e Interpretação Final**                    | Síntese do que foi aprendido com a modelagem, possíveis melhorias, limitações                               | 10%      |
| **8. Organização e Clareza do Código + Markdown explicativo** | Código bem comentado, células organizadas, explicações claras no Markdown                                   | 5%       |
| **Total**                                                 |                                                                                                             | **100%** |


📈 Métricas de Avaliação (Obrigatórias)

    MAE (Mean Absolute Error)

    RMSE (Root Mean Squared Error)

    R² (Coeficiente de Determinação)

    Interprete os valores de forma crítica: o modelo está representando bem os dados? O erro é aceitável?
